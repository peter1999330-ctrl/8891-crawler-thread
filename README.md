# 🚗 8891 中古車多執行緒平行爬蟲系統 (Tkinter GUI 版本)

本專案為 **8891 中古車多執行緒平行爬蟲與資料擷取視覺化系統**。透過現代工業級 `ThreadPoolExecutor` 線程池架構，全面突破傳統單執行緒爬蟲的等待瓶頸，並提供流暢現代的 **Tkinter** 視覺化圖形操作介面（GUI）。

---

## 🌟 核心功能特色

### 1. ⚡ 多執行緒平行採集加速 (Multi-Threaded Parallel Scraping)
* **自訂併發執行緒數量 (Threads / Workers)**：介面提供即時調整控制項（預設 4 執行緒，可自由設定 1 ~ 16 執行緒），充分榨乾網路頻寬與 CPU 效能。
* **`as_completed` 搶先交卷架構**：哪個頁面先響應就優先回傳處理，徹底消除長尾效應；資料並於後端依照頁碼由小到大自動重整排序。
* **介面零凍結 (Non-blocking UI)**：主程序與爬取任務完全解耦，搭配 `root.after()` 進行跨執行緒安全通訊，確保介面按鈕與視窗拖拉隨時絲滑流暢。
* **安全中斷 (Threading.Event)**：隨時可點擊「⏹ 停止採集」，背景執行緒將在安全節點中止並自動釋放資源。

### 2. 🚀 雙引擎彈性切換 (Dual-Engine Architecture)
* **Requests 極速併發（預設推薦）**：
  * 採用極輕量 HTTP 請求，多頁併發採集僅需數秒完成。
  * 記憶體佔用極低，適合大規模批次頁面數據爬取。
* **Selenium 模擬瀏覽器**：
  * 支援 Chrome 無頭模式（Headless）與完整瀏覽器渲染。
  * 抹除自動化測試特徵指紋（`AutomationControlled`），具備反爬蟲規避能力。
  * 具備 **Worker 實例池管理**（各執行緒獨立重用 WebDriver，避免重複啟閉 Chrome 的資源損耗，任務結束自動清理）。

### 3. 🔍 全站頁數秒級探測
* 一鍵探測 8891 官網目前的即時最大總頁數，支援點擊一鍵「⚡ 填入全站最大頁」。
* 提供「前1頁」、「前3頁」、「前5頁」、「前10頁」快速範本測試按鈕。

### 4. 📋 即時視覺化表格與統計 (Treeview & Data Viewer)
* **每頁採集即時渲染**：每完成一頁即時追加至表格中。
* **本地即時過濾檢索**：支援不分大小寫的關鍵字即時搜尋，無須重新發送網路請求。
* **行情價格動態統計**：即時計算當前抓取車輛的總筆數、平均售價、最低價與最高價。
* **雙擊開啟詳情**：滑鼠雙擊任意列可在瀏覽器中開啟該中古車原始刊登網頁；支援右鍵複製連結與標題。

### 5. 💾 資料儲存與匯出
* **SQLite 資料庫**：自動或手動存入 SQLite 資料庫（預設 `auto8891.db`），支援覆蓋（replace）或追加（append）模式。
* **CSV 匯出**：一鍵將已爬取清單匯出為 CSV 檔（採用 `UTF-8-SIG` 編碼，Excel 開啟絕不亂碼）。

## 🛠️ 安裝環境需求

本專案需要 Python 3.8+ 及以下相依套件：

```bash
pip install requests beautifulsoup4 lxml selenium pandas
```

*若使用 Selenium 引擎，請確保電腦已安裝 Google Chrome 瀏覽器（Selenium 4+ 已內建 Chrome 管理驅動）。*

---

## 🚀 執行方式

在專案目錄下執行以下指令即可開啟視窗介面：

```bash
python auto8891_crawler.py
```
